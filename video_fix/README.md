# Video Fix
Makes embedded videos on KU Leuven Ultra fit your screen, so you don't have to scroll inside the player to reach the controls (and it also just shows the full video now).

## Install
1. Install [Tampermonkey](https://www.tampermonkey.net/) (or another one).
2. Create a new script in Tampermonkey and paste in [`userscript.js`](userscript.js)
3. Reload Ultra
